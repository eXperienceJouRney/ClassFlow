# ClassFlow

ClassFlow 是一个面向大学生的课程管理与学习规划应用，旨在将 **课程表、课程任务和课程笔记** 整合到统一的学习管理流程中。

---

## 项目背景

大学生日常学习中通常需要同时管理：

- 课程时间
- 上课地点
- 作业与实验
- 考试与截止日期
- 课程笔记
- 临时通知与备忘

这些信息往往分散在课表 App、Todo 软件、备忘录以及课程群聊等不同平台中，信息之间缺乏关联。

ClassFlow 希望以 **课程** 为核心，将课程安排、任务和笔记连接起来，使用户能够更方便地管理自己的学习信息。

---

## 核心理念

ClassFlow 的核心理念是：

> **让课程不仅是一张时间表，而成为组织整个学习过程的入口。**

基本的信息组织方式为：

```text
学期
└── 课程
    ├── 任务
    └── 笔记
```

用户可以从一门课程直接查看或添加与该课程相关的任务和笔记，从而减少不同应用之间的切换。

## 计划功能

### 课程表

- 课程创建与编辑
- 课程时间与地点管理
- 日 / 周等课表视图
- 课程详情查看
- 课程颜色与分类
- 课表导入

### 任务管理

- 创建课程相关任务
- 设置任务截止时间
- 查看待完成任务
- 标记任务完成状态
- 从课程页面快速添加任务

### 课程笔记

- 为课程添加笔记或备忘
- 查看某门课程的历史记录
- 记录课堂通知、考试重点等信息

### 学期管理

- 创建和管理不同学期
- 设置当前学期
- 查看历史学期及课程信息

### 桌面组件

- 桌面组件：下一节课、今日课程、本周课表、待办

### 课程实时活动

- 灵动岛 / 锁屏显示当前课程的名称、起止时间与上课地点
- 剩余时间与课程进度按系统时间自动更新，App 不按秒刷新
- 展开态显示课程进度与下一节课，下课后自动收尾
- 入口只有设置 › 实时活动 ›「自动显示当前课程」：上课自动出现、下课自动结束，下一节开始时自动切换
- 尊重系统实时活动权限；用户手动收掉某节课后，本次课内不再自动重建
- 自动切换只在 App 运行 / 回到前台时保证，后台准点启动受 iOS 限制（见 iOS 端说明）

### 其他功能

后续可能逐步加入：

- 通知与提醒
- 搜索
- 数据导入与导出
- 更多个性化设置
