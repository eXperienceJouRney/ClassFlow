# ClassFlow

ClassFlow 是一个面向大学生的课程管理与学习规划应用，旨在将 **课程表、课程任务和课程笔记** 整合到统一的学习管理流程中。

本项目作为软件工程课程项目进行开发，同时也将尝试按照完整的软件工程流程推进，包括需求分析、产品设计、系统设计、开发实现、测试与项目文档维护。

> 当前项目处于早期开发阶段，部分功能和设计仍在持续完善中。

---

## 项目背景

大学生日常学习中通常需要同时管理：

- 课程时间
- 上课地点
- 作业与实验
- 考试与截止日期
- 课程笔记
- 临时通知与备忘

这些信息往往分散在课表 App、Todo 软件、备忘录以及课程群聊等不同平台中，信息之间缺乏关联。

ClassFlow 希望以 **课程** 为核心，将课程安排、任务和笔记连接起来，使用户能够更方便地管理自己的学习信息。

---

## 核心理念

ClassFlow 的核心理念是：

> **让课程不仅是一张时间表，而成为组织整个学习过程的入口。**

基本的信息组织方式为：

```text
学期
└── 课程
    ├── 任务
    └── 笔记
```

用户可以从一门课程直接查看或添加与该课程相关的任务和笔记，从而减少不同应用之间的切换。

## 计划功能

### 课程表

- 课程创建与编辑
- 课程时间与地点管理
- 日 / 周等课表视图
- 课程详情查看
- 课程颜色与分类
- 课表导入

### 任务管理

- 创建课程相关任务
- 设置任务截止时间
- 查看待完成任务
- 标记任务完成状态
- 从课程页面快速添加任务

### 课程笔记

- 为课程添加笔记或备忘
- 查看某门课程的历史记录
- 记录课堂通知、考试重点等信息

### 学期管理

- 创建和管理不同学期
- 设置当前学期
- 查看历史学期及课程信息

### 其他功能

后续可能逐步加入：

- 通知与提醒
- 搜索
- 桌面组件
- 数据导入与导出
- 更多个性化设置
